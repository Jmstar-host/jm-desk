# JM Desk · 本地 AI 桌面助手

一只住在桌面上的精灵。它帮你把邮件、飞书消息、会议纪要整理成**待办**和**需求**，到点提醒你订饭、下班，还能调用你接入的平台和知识库办事。数据都在你自己的电脑上。

开源（[MIT](LICENSE)），可以随意使用、修改和再分发。给 AI 看的二次开发文档在 [AGENTS.md](AGENTS.md)。

---

## 安装

| 系统 | 安装包 | 第一次打开 |
|---|---|---|
| macOS（Apple 芯片，M1–M4） | `JM Desk-<版本>-arm64.dmg` | 拖进「应用程序」。安装包没有签名，第一次要**右键 → 打开**。 |
| macOS（Intel 芯片） | `JM Desk-<版本>-x64.dmg` | 同上。不确定是哪种芯片：左上角  → 关于本机，看「芯片」或「处理器」。 |
| Windows（x64） | `JM Desk Setup <版本>.exe` | 运行安装程序。如果出现 SmartScreen 提示，点「更多信息 → 仍要运行」。 |

装好后，屏幕右下角会出现精灵「星灵 Lumi」。它不占 Dock，也不占任务栏；菜单栏（Windows 是托盘）里有它的小图标。

## 第一次使用（5 分钟）

1. **选模型**：右键精灵 → 设置 → 「模型」。可以填 API（DeepSeek 或其他兼容 OpenAI 的接口），也可以直接用本机已登录的 Claude Code、Codex 或 Ollama，不一定要买 API。
2. **知识库凭据**：如果你的安装包预置了公司知识库，到「设置 › 接入」填一次个人凭据（向管理员申请；可以粘贴，也可以填凭据文件的路径）。
3. **关联需求管理平台**（可选）：「设置 › 需求管理平台」，填平台地址 → 申请关联代码 → 在浏览器里点「允许」。
4. **提醒**：右键精灵 → 提醒。默认是工作日 10:30 订饭、12:00 吃饭、18:00 下班；把订餐页面的地址填上，点提醒就能直接去订饭。

## 日常怎么用

**点一下精灵**，弹出两圈泡泡：内圈是分组，外圈是功能。

| 分组 | 里面有什么 |
|---|---|
| 互动 | 瞬移、爆发、绕圈、冲刺、爱心、跟头、挥手 |
| 工作 | 助手、工作台、线索（这三个都在主窗口里，左边切换）、串门（去好友那里找资料） |
| 邮箱 | 打开邮箱、写邮件、未读统计 |
| 设置 | 设置（形象、气泡、需求管理平台、接入、模型都在里面）、提醒、自由飞、回到右下角 |

**主窗口**：右键精灵 →「打开 JM Desk」，或点「助手 / 工作台 / 线索」任何一个。左边一列切换三个页面，切走再回来内容都还在：
- **助手**：多轮对话，问知识库也在这里问。
- **工作台**：左边先看「我要处理的」——**待录入**（AI 从线索整理出、还没进平台的项目和需求）、**待推送**（改过还没推到平台的）、**我的待办**；下面是平台的结构（产品线 › 平台产品）。右边按平台的字段填写；改动先存本机，核对「改前 → 改后」后再推送，推送前会核对平台上是不是最新，别人改过同一处时让你选用谁的。
- **线索**：收到的原文；「信息源与记录」里开关信息源、看搬运记录和需求管理平台上的候选需求。

**右键精灵**：常用入口卡片，包括打开 JM Desk、提醒、设置、检查更新、自由活动开关和退出。**双击精灵**：回到右下角。**拖动**：放到你喜欢的位置。

功能窗口在精灵旁边弹出。点右上角的图钉可以**钉住**：钉住后点别处不会收起，还可以拖到顺手的位置。

### 三样东西，别混在一起

| | 是什么 | 在哪看 |
|---|---|---|
| **线索** | 收到的原文：邮件、飞书消息、会议纪要 | 「线索」窗口，每条下面写着从它整理出了什么 |
| **待办** | 从线索整理出的、**你自己**要做的跟进动作。分「需求跟进」（为推进某条需求）和「日常」 | 工作台（筛「待办」） |
| **需求池** | 某个**项目**里要完成的一件完整的事（新功能、优化、问题），按项目归集 | 工作台（筛「需求」） |

在工作台点「汇总新线索」时，AI 会读最近的线索，自动分出需求和待办，并挂到对应的项目下。分错了，在「工作台」里改一下就行；你改过的地方，AI 之后不会再动。

**提醒**（订饭、吃饭、下班）不算待办，在「提醒」面板里设置和查看。

### 助手和问知识

- **助手（对话工作台）**：一个可以多轮对话的窗口。直接说要办的事，例如「我还有哪些需求跟进的待办？」，可以接着往下问。它会调用你接入的工具去查、去办，每一步用了什么工具都列出来；要改数据之前一定先问你。左边是历史对话，上方可以勾选这次只用哪几个接入。
- **问知识**：在接入的知识库里检索。它会先确认你问的是哪个平台，回答里注明依据的资料；查不到就直说。

### 执行项目：把活交给本机的 Codex / DSH

助手只会调用工具查和办；要「动手做」的事（写文档、整理文件、写脚本）可以交给本机已经装好、登录好的 Codex 或 DSH。

1. 打开「助手」，新对话的「对象」选「＋ 新建执行项目」：起个名字、选执行者、选权限（可读写 / 只读）。JM Desk 会建一个独立的文件夹，执行者只在里面读写。
2. 把资料放进项目的 `inbox`，在对话里说要什么产出。它做了哪些命令、改了哪些文件都会列出来，产出在 `output`。可以接着上一轮往下说，也可以随时停止。
3. 在普通的助手对话里说「把这件事交给某某项目」，助手会先问你，再转派给执行者。

### 串门：让精灵去好友的桌面找资料

1. **加好友**：在「工作 › 串门」里，一方点「生成好友码」，另一方输入这 6 位数字。两边会各显示 4 个暗号，核对一致再点「加好友」。
2. **出门**：选好好友，再选「搬哪块」和「范围」（对方开放了什么，加好友后程序会自动拿到一份目录，只有名字没有内容），写下具体要什么内容，点「出发」。你的精灵会飞出屏幕。
3. **对方开门**：对方桌面上会飞来你的精灵，气泡里写明想从哪一块搬什么，问「帮它找」还是「请它回去」。也可以把某个好友设成「完全信任」，那样就自动放行。
4. **带回来**：对方只在**你选的那个范围**里找（默认只开放知识问答；邮件和聊天原文永远不开放；需求池和待办直接按词筛选，不耗对方的模型用量），找到后精灵抱着发光的包裹飞回你的桌面。结果存在「串门记录」里。

两台桌面通过一个中转服务互通，内容端到端加密，中转看不到内容。公司版已经预置了中转地址；开源版要自己部署一个中转（见 [docs/RELAY.md](docs/RELAY.md)），然后在「串门」页填入地址。

### 接入更多平台

「设置 › 接入」支持三种：

- **MCP · 本机命令**：例如 `npx -y 某个-mcp-server`。
- **MCP · 网址**：平台提供的 `https://…/mcp`。
- **平台 API**：填接口地址，有 OpenAPI 文档就自动生成每个接口的工具。

也可以一键导入 Claude Code、Cursor、Codex 里已经配好的 MCP。

每个工具都可以设成「自动 / 需确认 / 关闭」。会改数据的工具，默认每次调用前都要你确认。

## 隐私

- 邮件、聊天原文、工作列表都只存在本机的数据目录里（「设置 › 关于 › 打开数据目录」）。
- 密钥和凭据加密保存在系统钥匙串里，不写进配置文件，也不出现在日志里。
- 只有这几种情况会把内容发出去：
  - 你用的模型：汇总时会把线索交给它。如果不想让邮件和聊天离开电脑，在「设置 › 模型」勾选「只交给本机模型」。
  - 你接入的平台和知识库。
  - 你关联的需求管理平台：搬运时发送。
- 线索里写的指令只当作内容，助手不会照着执行。
- 串门：好友只能在你开放的范围里查（默认只有知识问答），每次都会先问你，除非你把对方设成了完全信任。消息端到端加密，中转看不到内容。

## 换形象、改气泡

- **形象**：「设置 › 形象」。内置的星灵 Lumi 可以改颜色、触角、大小；也可以导入你有权使用的 `.glb` 模型，或者从形象列表里下载。
- **气泡**：「设置 › 气泡」可以调整分组和顺序，也可以用一句话让 AI 帮你改。布局保存在 `layout.json`，直接编辑这个文件也会立即生效。

## 常见问题

- **精灵不见了**：点菜单栏（托盘）的图标，选「回到右下角」。
- **汇总很慢**：Codex 每次约 1.5 万 tokens、几十秒，适合低频任务。频繁使用建议用 API 或 Ollama，并在「设置 › 模型」里给每个任务排好先后顺序。
- **知识库连不上**：到「设置 › 接入」看看凭据是否显示「缺凭据」，然后点「测试」。
- **怎么升级**：如果发布方配置了升级地址，JM Desk 会自己联网检查（启动后、每 6 小时、电脑唤醒时），有新版本时精灵会冒气泡提醒，点「立即升级」即可，数据都会保留。1.1.x 的安装包没有带升级地址，要手动装一次新版本，之后才会自动收到。

## 给开发者

```bash
cd app && npm install && npm start      # 开发运行
npm test                                # 在仓库根目录运行测试
cd app && npm run dist:mac              # 打 macOS 安装包（Apple 芯片，arm64 dmg）
cd app && npm run dist:mac-x64          # 打 macOS 安装包（Intel 芯片，x64 dmg）
cd app && npm run dist:win              # 打 Windows 安装包（x64）
```

- **企业版预置接入**：`JM_DESK_PRESET=/path/to/integrations.json npm run dist:mac`。格式见 [presets/example.integrations.json](presets/example.integrations.json)。预置文件里只放地址和工具白名单，凭据由使用者自己填；打包完成后，仓库里的预置会自动清空。
- **升级地址**：`npm run set-update-feed -- https://…/latest.json`。发版步骤见 [AGENTS.md](AGENTS.md)。
- 目录结构、配置格式、扩展方式、底线规则都在 [AGENTS.md](AGENTS.md)。
